About FitBrigade


The Concept

FitBrigade is a web application designed to help fitness enthusiasts effectively plan and track their workouts. Focused on complete customization, it ensures you create a workout that's perfect for you. By creating your first workout, you join the fitness brigade; aka the "FitBrigade".


What's New in v3.0

  • Django Migration: Fully migrated from Flask to Django with PostgreSQL
  • User Authentication: Register, login, password reset, profile with photo
  • Workout Tracking: Full CRUD with muscle groups and exercises
  • Goals System: Set fitness goals, mark as complete, track progress
  • Statistics: Workout frequency by muscle group and goal completion rate
  • Messaging Inbox: Send, receive and archive messages between users
  • Real-time Validation: JavaScript form validation and toast notifications

Why This App?

Passionate about running, and more recently weight training, I understand the complexity of creating a varied training program and tracking progress. I wanted to create a tool that simplifies and optimizes workout planning, while remaining 100% customizable. This application helps you visualize the muscle groups you're working and maintain a balanced training program.


Technologies Used

  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
  • Backend: Django (Python)
  • Database: PostgreSQL with Django ORM
  • Hosting: Render.com
  • Version Control: Git & GitHub
